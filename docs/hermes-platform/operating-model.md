# Hermes Web Studio operating model

The operating model is proposal-first and approval-gated:
1. Audit and gather evidence.
2. Create `/output` reports and QMD indexes.
3. Use docs-only PRs when safe.
4. Defer source/workflow/runtime/build/evidence/Supabase/destructive work until explicit approval.
5. Use GitHub approved-write guard for every write.
6. Use security redacted triage for secret-like findings.
7. Run QMD update and hfinalize before final answer.

Key phrases: Hermes platform operating model; github approved write guard; post task finalization.
