# Multi-Agent Review Process

## Purpose

Simulated internal review across multiple roles before client delivery.

## Review Roles

1. Strategy Lead — audience/offer alignment, timeline realism
2. Conversion Copy Lead — CTA clarity, proof modules, forbidden claims
3. Compliance/Safety Reviewer — disclaimers, licensing proof, guarantees
4. QA Engineer — score, responsive CSS, accessibility markers
5. Client Delivery Manager — archive completeness, owner dependencies, deployment status

## Output

- `/output/production-v4-review-matrix.csv` — per-role findings per scenario
- `/output/production-v4-multi-agent-review.md` — consensus summary

## Safety

Internal simulation only. No real client data. No external sharing.
