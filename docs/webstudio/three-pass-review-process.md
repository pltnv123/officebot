# Three-Pass Review Process

## Pass 1 — Template Architect Review

Checks structure, UX hierarchy, conversion flow, component completeness, and whether the landing page architecture matches the intake.

## Pass 2 — Compliance/Claims Review

Checks forbidden claims, risk-sensitive wording, missing proof, and medical/financial caution gates.

## Pass 3 — Delivery QA Review

Checks assets, responsiveness, accessibility, handoff completeness, owner dependencies, and release readiness.

## Verdicts

- `PASS`
- `PASS_WITH_CAVEATS`
- `BLOCKED_BY_OWNER`
- `BLOCKED_BY_COMPLIANCE`
- `NEEDS_REVISION`

Output artifacts: `/output/webstudio-three-pass-review-report.md` and `/output/webstudio-three-pass-review-matrix.csv`.
