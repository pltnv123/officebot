# WebStudio Commercial V5 Operating System

## Purpose

Commercial V5 is a full sales-to-delivery operating system: opportunity → discovery → proposal → pricing → production → QA → delivery → post-launch.

## Scenarios

Eight simulated commercial opportunities covering diverse industries:

1. crypto-otc-premium-urgent-launch
2. luxury-clinic-booking-funnel
3. ai-automation-agency-b2b-leads
4. cross-border-logistics-b2b
5. cybersecurity-saas-trust-site
6. real-estate-villas-premium
7. legal-consulting-high-trust
8. ecommerce-premium-brand-refresh

## Local Artifacts

- Templates: `/workspace/templates/webstudio/v5/`
- Opportunities: `/workspace/deliverables/commercial-v5/`
- Client archives: `/output/client-delivery-archives-v5/`
- Dashboard: `/output/commercial-v5-executive-summary.md`

## Safety Guardrails

- No real client data
- No deployments
- No source/workflow/runtime/VPS/Supabase changes
- No secrets or raw credential values
- Owner/client integrations remain placeholders until approved
- No guaranteed outcomes or fake promises
