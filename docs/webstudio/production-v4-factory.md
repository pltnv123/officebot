# WebStudio Production V4 Factory

## Purpose

Production V4 is a full end-to-end simulated client delivery factory: intake → scope → estimate → architecture → content → copy → static site → QA → delivery archive.

## Scenarios

Five simulated production clients covering regulated and data-sensitive industries:

1. premium-crypto-otc-global-payments
2. luxury-aesthetic-clinic-booking-funnel
3. ai-automation-agency-lead-machine
4. b2b-logistics-cross-border-payments
5. cybersecurity-saas-trust-conversion

## Local Artifacts

- Templates: `/workspace/templates/webstudio/v4/`
- Simulated packages: `/workspace/deliverables/production-v4/`
- Delivery archives: `/output/delivery-archives/`
- Dashboard: `/output/webstudio-production-v4-dashboard.md`

## Safety Guardrails

- No real client data
- No deployments
- No source/workflow/runtime/VPS/Supabase changes
- No secrets or raw credential values
- Client-owned integrations remain placeholders until approved
