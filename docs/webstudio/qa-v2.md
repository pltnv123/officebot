# hwebqa v2

## Scope

`hwebqa-v2` is a local report-only static QA check for generated WebStudio simulated delivery packages.

## Checks

- Meta title and description
- Heading structure
- CTA clarity
- Forbidden claims
- Placeholder and owner dependencies
- Accessibility basics
- Mobile CSS markers
- Owner dependency blockers

## Outputs

- `/output/hwebqa-v2-report.md`
- `/output/hwebqa-v2-findings.csv`
- `/output/hwebqa-v2-release-verdicts.csv`

## Safety

No external calls, no deployment, and exit-zero report-only behavior.
