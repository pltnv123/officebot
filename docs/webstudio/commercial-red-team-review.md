# Commercial Red-Team Review

## Purpose

Simulated adversarial review across multiple roles before client delivery.

## Review Roles

1. Skeptical Client — trust, conversion, value concerns
2. Compliance Reviewer — legal review, substantiated claims, disclaimers
3. Delivery Manager — deployment blockers, owner dependencies
4. Technical QA — QA score, accessibility, responsive CSS

## Output

- `/output/commercial-v5-red-team-matrix.csv` — per-role findings per scenario (32 rows)
- `/output/commercial-v5-red-team-review.md` — summary and recommendations

## Top Findings

1. Compliance review required for regulated industries (high severity)
2. Trust/proof assets needed for skeptical clients (medium severity)
3. Owner dependencies block deployment (medium severity)
4. QA score thresholds must be met (low severity)

## Safety

Internal simulation only. No real client data. No external sharing.
