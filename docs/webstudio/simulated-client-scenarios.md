# Simulated Client Scenarios

Six fictional client packages were generated for hard-mode productization testing:

1. `regulated-crypto-otc-premium` — financial risk, compliance blocked until owner/legal review.
2. `luxury-clinic-missing-assets` — medical risk, blocked by missing assets and claim review.
3. `ai-agency-lead-router` — data-sensitive, ready with caveats and client-owned CRM dependency.
4. `logistics-b2b-international-payments` — regulated, blocked by owner dependency around payments/country coverage.
5. `real-estate-premium-villas` — medium risk, ready with caveats and asset/legal availability dependencies.
6. `saas-cybersecurity-startup` — data-sensitive, ready with caveats and proof/security dependencies.

Each package contains intake, requirements, risk classification, structure, copy deck, SEO brief, compliance checklist, static HTML/CSS site, QA checklist, delivery report, owner dependencies, and approval gates.

Generated websites are not committed to the repository and are not published.
