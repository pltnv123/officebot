# Web Studio Template Generator Guide

Use the local `webstudio-template-generator` skill to produce safe landing page briefs, copy, structures, estimates, QA checklists, and delivery reports.

## Output Boundaries
- `/output` for generated one-off artifacts.
- `/workspace/templates/webstudio` for reusable templates.

## Safety
- No client project changes without approval.
- Do not expose internal runbooks/tools.
- Do not promise fixed timelines/prices without scope and assumptions.
