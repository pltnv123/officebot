# WebStudio Delivery Operating Model

## Flow

Intake → estimate → UX/copy → implementation → QA → client review → revisions → production handoff.

## Gates

- Client assets approved.
- Legal/compliance review completed when needed.
- Forms/CRM/integrations approved separately.
- QA passed or caveats accepted.
- Rollback and support boundaries documented.

## Roles

- Intake Agent
- Analyst Agent
- Architect Agent
- Copywriter Agent
- Frontend Agent
- QA Agent
- Security Reviewer
- Delivery Manager

## Safety Rules

No fake promises, unapproved integrations, real deployment, source/workflow/runtime/VPS/Supabase change, or publication without explicit owner approval.
