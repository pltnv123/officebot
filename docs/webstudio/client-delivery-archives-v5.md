# Client Delivery Archives V5

## Purpose

Client delivery archives package commercial opportunities for handoff with all key documents.

## Structure

Each archive under `/output/client-delivery-archives-v5/<scenario>/` contains:

- `manifest.json` — file list with checksums
- `QA-scorecard.md` — link to QA scorecard
- `proposal.md` — link to proposal
- `scope-estimate.md` — link to pricing/scope
- `owner-dependencies.md` — link to dependency board
- `acceptance-criteria.md` — link to acceptance criteria
- `post-launch-roadmap.md` — link to roadmap
- `client-facing-README.md` — status and next steps

## Safety

- No external uploads
- No deployment
- Local packaging only
- No real client data
